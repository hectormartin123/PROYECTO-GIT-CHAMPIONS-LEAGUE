# Proyecto Git Champions League

**Integrantes:** Ever y Héctor

## Tema
Web sencilla sobre la UEFA Champions League 2026/2027.

## Descripción
Proyecto de la optativa de Git y GitHub (ASIX, Escola Balmes). Hemos hecho una
web sencilla para practicar el trabajo en equipo con ramas, commits, merges y
resolución de conflictos.

## Archivos y páginas
- `index.html`: página de inicio con el menú y un resumen
- `equipos.html`: equipos participantes
- `partidos.html`: resultados de los partidos
- `index.css`, `equipos.css`, `partidos.css`: estilos de cada página
- `script.js`: código JavaScript

## Cómo abrir la web
1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` con el navegador (doble clic).
